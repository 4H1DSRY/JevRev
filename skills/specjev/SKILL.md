# SpecJev compatibility alias

SpecJev was the development name. Use the JevRev skill at
[`../jevrev/SKILL.md`](../jevrev/SKILL.md) and call `jevrev run`.

The `specjev` binary and `rank` subcommand remain available for existing
scripts, but new integrations should use the JevRev names and the `shortlist`
field for unresolved review items.
